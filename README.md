# 🌐 E-Portfolio | นางสาวสุธีมา พงษ์ไพศาล
เว็บไซต์แฟ้มสะสมผลงานอิเล็กทรอนิกส์ (E-Portfolio) ของ **นางสาวสุธีมา พงษ์ไพศาล** นักเรียน **แผนการเรียนเทคโนโลยีและนวัตกรรม โรงเรียนธัญรัตน์** จัดทำขึ้นเพื่อรวบรวมประวัติการศึกษา ทักษะการเขียนโปรแกรม โครงงานนวัตกรรม และผลงานสร้างสรรค์ด้านการทำขนม
---

## 📌 เกี่ยวกับเว็บไซต์ (About)

เว็บไซต์นี้ได้รับการออกแบบภายใต้แนวคิด **"ผสานโค้ดดิ้งเข้ากับความคิดสร้างสรรค์"** โดยนำเสนอตัวตนของผู้จัดทำทั้งในด้านการเรียนสายเทคโนโลยีและนวัตกรรม ควบคู่กับความสามารถพิเศษด้านการทำขนมและเบเกอรี่ 

* **เจ้าของผลงาน:** นางสาวสุธีมา พงษ์ไพศาล
* **สถานศึกษา:** โรงเรียนธัญรัตน์ (แผนการเรียนเทคโนโลยีและนวัตกรรม)
* **ทักษะหลัก:** การพัฒนาเว็บไซต์ (HTML, CSS, JavaScript), Python, IoT เบื้องต้น และการทำขนม/เบเกอรี่
* **ธีมการออกแบบ:** โทนสี **เหลือง–แดง–ดำ** สะท้อนถึงความทันสมัย ความคิดสร้างสรรค์ และความมุ่งมั่น

---

## ✨ โครงสร้างและฟีเจอร์หลัก (Features)

1. **หน้าแรก (Hero Section):** แนะนำตัวตน แผนการเรียน พร้อมการ์ดข้อมูลในรูปแบบโค้ดและปุ่มลิงก์ไปยัง GitHub
2. **แนะนำตัว (About Me):** แสดงประวัติการศึกษา ปรัชญาการเรียนรู้ และหมวดหมู่ทักษะทั้งด้านเทคโนโลยีและการทำขนม
3. **ผลงาน (Portfolio & Projects):** แสดงการ์ดผลงานพร้อมคำอธิบาย เทคโนโลยีที่ใช้ และลิงก์ไปยังซอร์สโค้ดบน GitHub รองรับ **ปุ่มตัวกรองหมวดหมู่ (Filter)** แบบโต้ตอบ:
   * เว็บไซต์และโค้ดดิ้ง
   * เทคโนโลยีและนวัตกรรม
   * เบเกอรี่และงานสร้างสรรค์
4. **กิจกรรม (Activities & Experiences):** รวบรวมประสบการณ์การเข้าร่วมค่ายอบรม นิทรรศการโครงงาน และกิจกรรมสร้างสรรค์ในโรงเรียน
5. **ส่วนท้ายเว็บไซต์ (Footer):** รวบรวมเมนูลัดและช่องทางติดต่อสาธารณะ
6. **Responsive Design:** รองรับการแสดงผลอย่างเหมาะสมทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ (พร้อมเมนู Hamburger สำหรับมือถือและปุ่มเลื่อนกลับด้านบน)

---

## 🛠️ เทคโนโลยีที่ใช้พัฒนา (Tech Stack)

* **HTML5:** โครงสร้างเว็บไซต์เชิงความหมาย (Semantic HTML)
* **CSS3:** จัดวางเลย์เอาต์ด้วย Flexbox & CSS Grid, ตัวแปรสี (CSS Variables) และแอนิเมชัน
* **Vanilla JavaScript:** ระบบกรองหมวดหมู่ผลงาน, เมนูบนอุปกรณ์พกพา และ Scroll Spy
* **Google Fonts:** ฟอนต์ภาษาไทย [Prompt](https://fonts.google.com/specimen/Prompt)
